# 📝 Lista de Tarefas

Projeto simples de uma lista de tarefas desenvolvido para praticar os fundamentos do desenvolvimento web.

## 🚀 Tecnologias utilizadas

- HTML5
- JavaScript
- CSS

## ✨ Funcionalidades

- Adicionar novas tarefas.
- Marcar tarefas como concluídas.
- Excluir tarefas.
- Acompanhar o contador de tarefas concluídas.

## 🎯 Objetivo

Praticar conceitos básicos de programação, manipulação do DOM e eventos em JavaScript.
